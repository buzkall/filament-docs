# Introduction

This is the user manual of the panel. Every screen in the menu has its own page here, in the same groups and order as the panel's navigation, and you only see the pages of the screens you can open.

## How to use this guide

- Pick a screen in the menu on the left, or search for any word.
- Each page explains what the screen is for and how to use it.

> [!TIP]
> Link to another page by linking to its file, for example `[Users](users.md)`.
